​🌾 Punjabi Land Calculator | ਪੰਜਾਬੀ ਜ਼ਮੀਨ ਕੈਲਕੁਲੇਟਰ
​A comprehensive web application for land measurement, price calculation, and land division using traditional Punjabi units.
(ਪੰਜਾਬੀ ਇਕਾਈਆਂ ਵਿੱਚ ਜ਼ਮੀਨ ਦੀ ਮਿਣਤੀ, ਰੇਟ ਕੱਢਣ ਅਤੇ ਵੰਡ ਕਰਨ ਲਈ ਇੱਕ ਬਿਹਤਰੀਨ ਵੈੱਬ ਐਪ)
​📖 About (ਬਾਰੇ)
​🇮🇳 Punjabi
​ਇਹ ਪ੍ਰੋਜੈਕਟ ਪੰਜਾਬ ਵਿੱਚ ਜ਼ਮੀਨ ਦੀ ਮਿਣਤੀ ਕਰਨ ਲਈ ਬਣਾਇਆ ਗਿਆ ਹੈ। ਇਹ ਐਪਲੀਕੇਸ਼ਨ ਕਿਸਾਨਾਂ, ਪ੍ਰੋਪਰਟੀ ਡੀਲਰਾਂ ਅਤੇ ਆਮ ਲੋਕਾਂ ਲਈ ਬਹੁਤ ਲਾਹੇਵੰਦ ਹੈ। ਇਸ ਦੀ ਮਦਦ ਨਾਲ ਤੁਸੀਂ ਆਸਾਨੀ ਨਾਲ ਜ਼ਮੀਨ ਨੂੰ ਕਿੱਲੇ, ਕਨਾਲ, ਮਰਲੇ ਅਤੇ ਵਿੱਘੇ ਵਿੱਚ ਬਦਲ ਸਕਦੇ ਹੋ। ਇਹ ਇੱਕ PWA (Progressive Web App) ਹੈ, ਮਤਲਬ ਤੁਸੀਂ ਇਸਨੂੰ ਆਪਣੇ ਫੋਨ ਵਿੱਚ ਇੰਸਟਾਲ ਕਰ ਸਕਦੇ ਹੋ ਅਤੇ ਬਿਨਾਂ ਇੰਟਰਨੈੱਟ (Offline) ਵੀ ਵਰਤ ਸਕਦੇ ਹੋ।
​🇬🇧 English
​This project is designed to facilitate land calculations in the Punjab region. It is highly useful for farmers, real estate agents, and the general public. With this app, you can easily convert land measurements into traditional units like Killa (Acre), Kanal, Marla, and Bigha. It is a PWA (Progressive Web App), meaning it can be installed on your phone and works completely offline.
​✨ Features (ਖਾਸਿਅਤਾਂ)
​1. Land Area Calculator (ਜ਼ਮੀਨ ਮਿਣਤੀ)
​Conversions: Convert between Acre, Bigha, Kanal, Marla, Gaj, Sq. Ft, Sq. Meter, etc. (ਕਿੱਲਾ, ਕਨਾਲ, ਮਰਲਾ, ਵਿੱਘਾ, ਗਜ ਆਦਿ ਵਿੱਚ ਬਦਲੀ)।
​Dimensions: Calculate area by entering Length × Width in:
​Feet (ਫੁੱਟਾਂ ਰਾਹੀਂ)
​Meters (ਮੀਟਰਾਂ ਰਾਹੀਂ)
​Karams (ਕਰਮਾਂ ਰਾਹੀਂ - 1 Karam = 5.5 Ft)
​Triangle Land: Calculate area for triangular plots (ਤਿਕੋਣੀ ਜ਼ਮੀਨ ਦੀ ਮਿਣਤੀ)।
​2. Price Calculator (ਰੇਟ ਪਤਾ ਕਰੋ)
​Enter the rate for one unit (e.g., Rate per Acre), and it automatically calculates the price for all other units (Marla, Gaj, Sq. Ft, etc.).
​(ਕਿਸੇ ਵੀ ਇੱਕ ਇਕਾਈ ਦਾ ਰੇਟ ਭਰੋ, ਬਾਕੀ ਸਾਰੀਆਂ ਇਕਾਈਆਂ ਦਾ ਰੇਟ ਆਪਣੇ ਆਪ ਨਿਕਲ ਜਾਵੇਗਾ)।
​3. Land Divider (ਜ਼ਮੀਨ ਵੰਡੋ)
​Enter the total land (Killa, Kanal, Marla) and the number of people.
​The app calculates exactly how much land comes to each person's share.
​(ਕੁੱਲ ਜ਼ਮੀਨ ਭਰੋ ਅਤੇ ਹਿੱਸੇਦਾਰ ਦੱਸੋ, ਐਪ ਹਰੇਕ ਦੇ ਹਿੱਸੇ ਆਉਂਦੀ ਜ਼ਮੀਨ ਦੱਸੇਗੀ)।
​4. Technical Features (ਤਕਨੀਕੀ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ)
​Dark Mode: Switch between Light and Dark themes (ਰਾਤ ਲਈ ਡਾਰਕ ਮੋਡ)।
​Offline Support: Works without internet using Service Worker (ਬਿਨਾਂ ਨੈੱਟਵਰਕ ਚਲਦੀ ਹੈ)।
​Installable: Can be installed as a native app on Android/iOS (ਫੋਨ ਵਿੱਚ ਐਪ ਵਾਂਗ ਸੇਵ ਹੁੰਦੀ ਹੈ)।
​Responsive: Works on all mobile and desktop screens.
​🚀 How to Use (ਵਰਤੋਂ ਕਿਵੇਂ ਕਰੀਏ)
​Open the Link: Visit the live URL of the project.
​Install App: Click on the "Install" button in the footer banner to add it to your home screen.
​Select Tab: Use the tabs at the top to switch between Area (ਮਿਣਤੀ), Price (ਰੇਟ), or Divide (ਵੰਡ).
​Input: Enter the values in the input boxes. The results will update automatically.
​🛠️ Technology Stack (ਵਰਤੀਆਂ ਗਈਆਂ ਤਕਨੀਕਾਂ)
​HTML5: Structure of the app.
​CSS3: Styling, Grid Layout, and Dark Mode variables.
​JavaScript (Vanilla): Logic for calculations and DOM manipulation.
​Service Worker: For caching files and offline functionality (sw.js).
​Manifest.json: For PWA configuration and styling.
