🌾 Land Calculator Punjabi (ਜਮੀਨ ਮਿਣਤੀ ਕੈਲਕੁਲੇਟਰ)
ਇਹ ਇੱਕ ਪ੍ਰੋਗਰੈਸਿਵ ਵੈੱਬ ਐਪ (PWA) ਹੈ ਜੋ ਪੰਜਾਬ ਵਿੱਚ ਜਮੀਨ ਦੀ ਮਿਣਤੀ ਕਰਨ ਲਈ ਬਣਾਈ ਗਈ ਹੈ। ਇਹ ਐਪ ਇੰਟਰਨੈੱਟ ਤੋਂ ਬਿਨਾਂ (Offline) ਵੀ ਕੰਮ ਕਰਦੀ ਹੈ।
This is a Progressive Web App (PWA) designed for land measurement calculations using standard Punjabi units. It works completely Offline.
🇮🇳 ਪੰਜਾਬੀ (Punjabi Description)
🌟 ਖਾਸੀਅਤਾਂ (Features)
 * ਸਾਰਾ ਹਿਸਾਬ ਇੱਕੋ ਥਾਂ: ਕਿੱਲਾ, ਕਨਾਲ, ਮਰਲਾ, ਵਿੱਘਾ, ਗਜ, ਸਕੇਅਰ ਫੁੱਟ ਅਤੇ ਸਕੇਅਰ ਮੀਟਰ ਵਿੱਚ ਬਦਲੀ।
 * ਆਫਲਾਈਨ (Offline): ਇੱਕ ਵਾਰ ਚਲਾਉਣ ਤੋਂ ਬਾਅਦ, ਬਿਨਾਂ ਇੰਟਰਨੈੱਟ ਦੇ ਚੱਲਦੀ ਹੈ।
 * ਕਰਮਾਂ ਰਾਹੀਂ ਹਿਸਾਬ: ਜਗ੍ਹਾ ਦੀ ਲੰਬਾਈ ਅਤੇ ਚੌੜਾਈ (ਕਰਮਾਂ ਵਿੱਚ) ਭਰੋ, ਰਕਬਾ ਆਪਣੇ ਆਪ ਨਿਕਲ ਜਾਵੇਗਾ।
 * ਫੁੱਟਾਂ ਰਾਹੀਂ ਹਿਸਾਬ: ਜਗ੍ਹਾ ਦੀ ਲੰਬਾਈ ਅਤੇ ਚੌੜਾਈ (ਫੁੱਟਾਂ ਵਿੱਚ) ਭਰੋ।
 * ਸੌਖਾ ਡਿਜ਼ਾਈਨ: ਸਾਰਾ ਕੁਝ ਇੱਕ ਹੀ ਸਕਰੀਨ 'ਤੇ, ਬਿਨਾਂ ਸਕਰੋਲ ਕੀਤੇ।
📲 ਫੋਨ ਵਿੱਚ ਐਪ ਵਾਂਗ ਕਿਵੇਂ ਚਲਾਉਣਾ ਹੈ?
 * ਦਿੱਤੇ ਗਏ ਲਿੰਕ ਨੂੰ Chrome (Android) ਜਾਂ Safari (iPhone) ਵਿੱਚ ਖੋਲ੍ਹੋ।
 * ਮੋਬਾਈਲ ਦੇ ਮੀਨੂ (3 ਬਿੰਦੀਆਂ) ਵਿੱਚ ਜਾਓ।
 * "Add to Home Screen" (ਹੋਮ ਸਕ੍ਰੀਨ 'ਤੇ ਜੋੜੋ) ਵਾਲਾ ਬਟਨ ਦਬਾਓ।
 * ਇਹ ਤੁਹਾਡੇ ਫੋਨ ਵਿੱਚ ਇੱਕ ਐਪ ਵਾਂਗ ਇੰਸਟਾਲ ਹੋ ਜਾਵੇਗੀ।

🇬🇧 English (English Description)
🌟 Features
 * All-in-One Conversion: Convert seamlessly between Acres (Killa), Kanal, Marla, Bigha, Sq. Yards (Gaj), Sq. Feet, and Sq. Meters.
 * Works Offline: Fully functional without an internet connection after the first load (PWA).
 * Calculate by Karams: Enter Length x Width in Karams to get the exact area.
 * Calculate by Feet: Enter Length x Width in Feet to get the area.
 * Compact Design: User-friendly interface that fits on a single screen without scrolling.
📲 How to Install on Mobile?
 * Open the live link in Chrome (Android) or Safari (iOS).
 * Tap on the Menu (3 dots) or Share button.
 * Select "Add to Home Screen".
 * The app will be installed on your device and can be used offline.
